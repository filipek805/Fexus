# Code of Conduct

Fexus is a technical project and contributors are expected to communicate respectfully.

Unacceptable behavior includes:

- harassment
- personal attacks
- discrimination
- threats
- doxxing
- deliberate disruption
- unwanted sexual attention

Maintainers may remove contributions or restrict participation when behavior violates this policy.

Report serious concerns privately to the maintainers rather than starting a public argument in an issue or pull request.
